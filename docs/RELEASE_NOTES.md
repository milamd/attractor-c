# C remediation release notes

Implementation follows phases 0–8 of the October 8 plan. This is a source/API migration, not an ABI-compatible library update. Apple silicon is the sole deployment architecture, per the October 9 scope amendment. Release qualification on the proposed minimum macOS 13 remains pending.

The changes repair fan-in ownership; truncated parsers; fail-open approval; shell-injected filesystem/search operations; artifact traversal/collisions; ineffective timeouts; workflow failure/retry/goal routing; unsafe resume; duplicate/incomplete branch execution; lost child configuration; unchecked allocations and raw reads; empty edits; cleanup leaks; aliasing; permissive JSON; and persistence/capability/build gaps. See the [verification map](remediation-verification.md) for regression evidence.

API consumers must rebuild. Significant changes include `Answer.kind`, `ExecutionEnv.read_raw` and process configuration, callback userdata and explicit tool-error flags, registry failure state, pipeline execution environment/cancellation/budgets, graph/context layout, JSON builder failure/number state, deep message cloning and opaque provider metadata. `GenerateResult` now owns its response; borrowed tool calls and finish text expire with its destructor. Requests and event arguments are borrowed. Initialize errors/checkpoints to zero and use the documented destructors. Provider registration transfers ownership; provider close releases nested state. Edge collection now returns total counts, including when capacity is insufficient.

Checkpoint version 2 stores committed routing, full outcomes/history and pending-effect state. Earlier checkpoints are rejected; automatic migration would invent missing routing/approval information. Do not treat absent or edited status artifacts as recovery evidence. Inspect/reconcile an ambiguous attempt before intentionally retrying external effects. Atomic synchronized writes report failure, including after a replacement if directory synchronization fails.

Human EOF/cancellation/invalid answers fail closed; automatic approval remains explicit. Failure cannot fall through ordinary edges, stale preferred labels are cleared, latest goal outcomes control completion, and exhaustion fails. Branches execute their full isolated paths sequentially and meet at the join without redispatch; conflicts fail and supported join/error policies are explicit. Child failures and inherited configuration are retained.

Streaming, vision/audio/documents, response formats, stop sequences, raw provider options, concurrent branch execution and concurrent session steering are not advertised as available. Reasoning-effort control is OpenAI-only; other adapters retain supported returned metadata but reject explicit effort configuration. `--dry-run` still permits shell/child effects. The [decisions](decisions/2026-10-08-remediation.md) pin the reviewed specification and explain intentional stricter behavior and context-merging differences.
